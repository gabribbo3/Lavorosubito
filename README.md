# LavoroSubito

MVP web responsive del marketplace per interventi urgenti locali.

## Funzioni presenti
- scelta categoria professionista
- selezione urgenza: SUBITO / OGGI / 48H
- richiesta demo
- sezione professionisti
- stato disponibilità online/offline
- layout responsive per smartphone e desktop

## Avvio locale
Richiede Node.js 20+.

```bash
npm install
npm run dev
```

Apri `http://localhost:3000`.

## Pubblicazione
Il progetto è pronto per essere importato in Vercel da GitHub.
